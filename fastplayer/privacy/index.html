本ポリシーは、Mac向けアプリ「FastPlayer」と紹介・サポート用公開ページにおける情報の取り扱いを説明します。

動画保護では、動画本体をGoogleへ送信しません。
Googleのサインイン情報を本人確認に使い、動画ごとの暗号鍵と識別情報を本人のDriveアプリ専用領域へ保存します。通常のローカル再生にGoogleサインインは不要です。

1. Googleアカウントと動画保護

保護動画の作成・再生を選択した場合にGoogle OAuthを利用します。一度許可した後は、起動時に保存済み認証でGoogle本人確認し、サインイン状態の復帰を確認します。明示的にサインアウトした後は自動復帰しません。要求する権限は openid、email、https://www.googleapis.com/auth/drive.appdata です。GoogleのパスワードをFastPlayerや提供者へ入力する必要はありません。認証はGoogleの画面で行います。

  • Googleの一意のアカウント識別子・メールアドレス：本人確認、鍵の所有者の照合、サインイン中アカウントの表示に使用します。識別子はDriveの鍵レコードと端末の認証情報に含まれます。メールアドレスはサインイン中の表示に使用します。
  • アクセス・更新トークン：Google本人確認、許可されたDrive領域へのアクセス、認証更新に使用します。アクセス用トークンはメモリ上、更新トークンなどの継続利用情報はMacのKeychainに保存します。
  • 動画鍵と識別情報：動画ごとのランダムな暗号鍵、動画UUID、所有者識別子、形式バージョンを、本人のGoogle Driveの非公開アプリデータ領域（appDataFolder）に保存します。処理中は端末のメモリでも使用します。
  • 動画本体：保護機能からGoogleや提供者のサーバーへアップロードしません。端末内で暗号化し、再生時は必要な範囲をメモリ上で復号します。動画全体の平文一時ファイルは作りません。

Driveに保存する鍵レコードには、元動画のファイル名や動画本体を含めません。通常のDriveファイルを広く閲覧する権限は要求しません。Google側の処理には Googleのプライバシーポリシー も適用されます。

2. 端末内の情報

選択した動画・音声・字幕・コミック、ライブラリ情報、再生位置、プレイリスト、設定などを、対応する機能の提供のために端末内で扱います。利用者が選んだ保存先に保護動画や書き出しファイルを保存します。フォルダ保護では、相対ファイル名、変換の成否・未処理の理由、時刻などを変換結果ファイルに記録します。この結果に動画本体や動画鍵は含めず、Googleや提供者へ送信しません。端末のバックアップや指定した同期フォルダには、OS・保存サービスの設定も適用されます。ネットワーク接続先のブックマークや認証情報を利用者が登録する場合があり、対応する機能では接続用パスワードなどの保存にKeychainを使用します。

3. 任意の通信・購入

  • ネットワーク再生・メディアサーバー：利用者が指定した配信元やサーバーへ接続します。相手方には要求内容、IPアドレス、必要な認証情報などが伝わります。
  • オンライン字幕：検索・ダウンロードを行う場合、対応サービスへ動画の識別用ハッシュ、検索用のファイル名、希望言語などを送ることがあります。ログインする場合は、そのサービスの認証情報を使用します。
  • 共有・書き出し・LAN配信：利用者が選んだ機能に応じて、ファイルや映像・音声・字幕を指定した保存先、アプリ、機器へ渡します。
  • アプリ内購入：購入・支払い・復元はAppleのStoreKitを利用し、アプリは購入状態の確認に必要な取引情報を扱います。クレジットカード情報などを提供者がアプリから取得することはありません。Appleの処理には Appleのプライバシーポリシー が適用されます。

4. Googleデータの利用制限・外部送信

Google動画保護の通信は、本人確認・認証更新・Driveアプリデータへの鍵保存と取得に使用します。提供者が動画鍵やGoogle認証情報を保管する独自の鍵管理サーバーは設けていません。

Google APIから受け取った情報の利用・他のアプリへの転送は、Google API Services User Data Policy のLimited Use要件を含む規定に従います。Googleユーザーデータを販売したり、広告配信、行動ターゲティング、信用判断、汎用AIモデルの学習に利用したりしません。開発者が利用者のGoogleデータを通常業務で閲覧する仕組みはありません。

第三者の広告・追跡SDKは組み込んでいません。閲覧履歴やGoogleユーザーデータを開発者の解析サーバーへ自動送信する機能も設けていません。利用者が選ぶ第三者サービスや共有先には、それぞれの条件が適用されます。

5. 保存・許可の取消し・削除

  • 動画や書き出しファイル、共有先のコピーは各保存先から削除できます。ライブラリからの除外と元ファイル自体の削除は区別してください。
  • Googleからサインアウトすると利用中の認証状態を破棄し、保護再生を終了します。サインアウトだけでは、Driveにある動画鍵や保護動画を削除しません。
  • Googleへのアクセス許可は Googleアカウントの接続管理 で取り消せます。Macに保存された認証情報の削除にはOSのKeychain管理機能も利用できます。
  • 動画鍵は利用者がGoogle Drive側でアプリデータを削除するまで保存されます。鍵の削除やGoogleアカウントの喪失により、対応する保護動画は復号できなくなります。提供者は失った鍵を再発行して元の動画を復元できません。元動画は別途保管してください。
  • アプリを削除しても、保存先の動画、Keychain項目、Drive上のアプリデータがすべて消えるとは限りません。各保存先で管理してください。

6. 保護とその限界

動画にAES-256-GCMによる認証付き暗号化を行い、Googleとの通信にはHTTPSを使用します。保護動画の作成・再生ではオンラインの本人確認と鍵取得を行い、再生中も定期的に確認します。認証・許可・通信・鍵の照合に失敗した場合、作成または再生を継続しません。

許可された端末の管理者や改変されたアプリからの抽出、画面収録などを完全に防ぐハードウェアDRMではありません。端末、Googleアカウント、バックアップの管理も重要です。

7. 公開ページ・お問い合わせ・変更

この公開ページに広告やアクセス解析スクリプトは設置していません。GitHub Pagesで配信しており、配信に伴う技術的なアクセス情報の扱いには GitHubのプライバシーステートメント が適用されます。

問い合わせとして送信いただいた連絡先や内容は、回答・調査に必要な範囲で使用します。Googleのパスワード、認証トークン、動画鍵を添付しないでください。取り扱いを変更する場合は本ページで更新日と内容を案内し、Googleユーザーデータの新たな利用など同意が必要な変更は、利用を始める前に必要な案内・同意取得を行います。お問い合わせは support@estechfy.com へご連絡ください。
