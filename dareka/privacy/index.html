1. 本アプリで扱う情報と各権限の利用目的（顕著な開示）

(1) Googleアカウント認証および Google Drive 非公開領域（openid, email, https://www.googleapis.com/auth/drive.appdata）［必須］

  • 扱う情報：Googleアカウントの一意識別子・メールアドレス、および利用者が本アプリに登録した名刺情報・名刺表裏画像・ゴミ箱データ・プライベート電話帳・Dareka着信記録（記録設定が有効な場合）。
  • 利用目的：端末内でアカウントごとに専用のデータベース領域を分離管理するため、および利用者ご自身の Google Drive 内の非公開アプリ専用領域（appDataFolder）へ自動バックアップ・復元を行うために使用します。
  • アクセス範囲：本アプリ専用の非公開領域（appDataFolder）のみにアクセスし、利用者の Google Drive 上の他の一般ファイルやフォルダには一切アクセスしません。

(2) 着信識別ロール（ROLE_CALL_SCREENING / DarekaCallScreeningService）［推奨］

  • 扱う情報：電話着信時にOSから渡される着信電話番号。
  • 利用目的：端末内の登録済み名刺、プライベート電話帳、公開番号辞書（公的機関・主要企業・迷惑電話注意データ）、および（許可されている場合）端末の連絡先と端末内で照合し、発信者の会社名・部署・役職・氏名・注意カテゴリを着信ポップアップまたは通知で表示するために使用します。
  • 通話の非遮断：本アプリが着信を自動的に拒否・遮断（ブロック）することはありません。

(3) 通話履歴の参照（android.permission.READ_CALL_LOG）［任意］

  • 扱う情報：端末内の通話履歴（電話番号・発着信日時・通話種別・通話時間）。
  • 利用目的：着信履歴タブにおいて発着信・不在着信ログを表示し、登録済みの名刺やプライベート電話帳の名前と照合して表示するため、また未登録の電話番号をワンタップでプライベート電話帳や名刺へ登録できるようにするために使用します。
  • 保存・送信に関する厳格な制限：OSの通話履歴リスト自体（利用者が自ら登録を選択していない番号や発着信日時・通話時間）を本アプリのデータベースへ複製保存したり、Google Drive や外部サーバーへ送信・アップロードすることは一切ありません。利用者が自ら選択してプライベート電話帳や名刺に登録した番号・表示名のみが保存および Google Drive 自動バックアップの対象となります。

(4) 端末の連絡先照合（android.permission.READ_CONTACTS）［任意］

  • 扱う情報：端末の標準連絡先に登録されている電話番号と表示名。
  • 利用目的：着信時および着信履歴画面で、電話番号が端末の標準連絡先に登録されている場合にその表示名を参照・表示するために使用します。
  • 保存・送信に関する厳格な制限：端末の標準連絡先リストを外部サーバーや Google Drive へ送信・アップロードすることは一切ありません。すべての照合処理は端末内で完結します。

(5) 他のアプリの上に重ねて表示（android.permission.SYSTEM_ALERT_WINDOW）［任意］

  • 利用目的：電話着信時に他のアプリやロック画面の前面へ、発信者の名刺情報・プライベート電話帳カードをポップアップ表示するためにのみ使用します。

(6) 通知へのアクセス（android.permission.BIND_NOTIFICATION_LISTENER_SERVICE / 楽天Link対応）［任意］

  • 扱う情報：利用者が「設定」で「楽天Linkの着信にも対応」を有効にした場合のみ、Rakuten Link アプリ（jp.co.rakuten.mobile.rcs）の着信通知に含まれる電話番号。
  • 利用目的：標準の電話回線だけでなく Rakuten Link 着信時にも発信者情報をポップアップ表示するために使用します。他アプリの通知内容は一切読み取り・保存・外部送信しません。

(7) カメラ（android.permission.CAMERA）および端末内AI文字認識（OCR）［任意］

  • 扱う情報：撮影した名刺の表面・裏面画像および認識テキスト。
  • 利用目的：名刺の撮影および氏名・会社名・部署・役職・連絡先の自動解析のために使用します。
  • 処理方式：文字認識および項目解析は端末内のOS標準機能（Android: Google Play 開発者サービス ML Kit Text Recognition / iOS: Apple Vision Framework）と内蔵辞書によりオフラインで実行されます。APIキーの登録や外部AIサーバーへの画像送信は不要です。

2. 外部通信が発生する機能とデータの保存設計

  • Google Drive（appDataFolder）への自動バックアップ通信（HTTPS暗号化）：ログイン中のアカウントで名刺やプライベート電話帳を追加・更新・削除すると、HTTPS通信により利用者ご自身の Google Drive（appDataFolder）へ自動保存されます。
  • Android OS 標準バックアップの無効化：本アプリは android:allowBackup="false" を設定しており、本アプリのアカウント分離管理外で Android OS 標準の自動バックアップによりデータベースが複製されることはありません。
  • 未登録番号の自動検索（初期状態：OFF）および手動Web検索：「設定」画面で「未登録番号を自動検索」を利用者が明示的にONにした場合のみ、未登録番号からの着信時に該当電話番号を Google 検索へ送信します（初期状態はOFFです）。また、利用者が手動で「Webで番号検索」「マップで開く」「郵便番号から住所入力（zipcloud API）」を実行した場合は、該当する検索文字列・郵便番号を各サービスへ送信します。
  • アプリ更新・公開番号辞書のバージョン確認：アプリの起動・復帰時に最新バージョン情報を確認するため配信定義URLへ接続します（個人データは一切送信しません）。

3. Googleユーザーデータの利用制限（Limited Use）

本アプリが Google API から受け取る情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。Googleユーザーデータを第三者へ販売したり、広告配信・ターゲティング・信用判断・AIモデルの学習に利用することは一切ありません。

4. データの保持期間と削除方法（アカウントデータおよびクラウド保存データの削除）

利用者は、本アプリ内のデータおよび Google Drive（appDataFolder）に保存されたデータをいつでも削除できます（専用案内ページ：アカウント・データ削除手順）。

  • アプリ内での個別削除：名刺、ゴミ箱、プライベート電話帳、Dareka着信記録（最大1,000件）はアプリ内からいつでも削除できます。
  • アプリ内からの「アカウントデータの完全削除」（端末＋Google Drive 一括削除）：アプリ内の「設定」＞「アカウントデータの完全削除」を実行すると、端末内のアカウント専用データ（名刺・画像・ゴミ箱・プライベート電話帳・Dareka着信記録）および Google Drive（appDataFolder）上のすべての自動保存スナップショットを即座に完全削除し、ログアウトできます。
  • アンインストール後の Web からの削除手順：アプリをアンインストールした後でも、PCブラウザ版 Google Drive の「設定（歯車アイコン）」＞「設定」＞「アプリの管理」＞「Dareka」＞「オプション」＞「非表示のアプリデータを削除」からクラウド上のデータを完全に削除でき、Googleアカウントのサードパーティ接続管理 から「Dareka」のアクセス権をいつでも解除できます。

5. 免責事項（発信番号偽装に関するご注意）

着信時に表示される発信者電話番号は、通信経路上で技術的に偽装（スプーフィング）される可能性があります。名刺・プライベート電話帳・公開番号辞書との一致表示は発信者本人の真正性や安全性を保証するものではありません。金銭や暗証番号・個人情報を求める不審な電話には十分ご注意ください。

6. お問い合わせ窓口・ポリシーの変更

本ポリシーに関するお問い合わせは support@estechfy.com までご連絡ください。本ポリシーを変更する場合は、本ページおよびアプリ内の「プライバシーと権限のご案内」画面にて改定日とともに公表します。
